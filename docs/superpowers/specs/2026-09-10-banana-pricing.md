## 2. 하나로AI스튜디오 정책

### 단위
- **1 ro = 100원(정가)**. 모든 화면과 장부는 ro로 표기한다.

### 얻는 방법
| 방법 | 내용 |
|---|---|
| 가입 보너스 | 가입 즉시 **30B** (문서·뉴스레터 체험용) |
| ro 충전(일회성) | 아래 패키지. 유효기간 없음. 7일 이내 미사용분 환불 |
| 월 정액 구독 | 99,000원/월 → 매월 **1,300B** 지급(76원/B, 프로 패키지와 동일 수량을 정기 할인가로). 결제일에 잔여분 소멸 없이 누적하지 않음: 월 지급분은 30일 유효, 충전분은 무기한 |

### 충전 패키지 (지니젠과 동일 수량·가격)
| 패키지 | ro | 가격 | ro당 | 할인 |
|---|---|---|---|---|
| 베이직 | 120B | 10,000원 | 83원 | -17% |
| 밸류 | 625B | 50,000원 | 80원 | -20% |
| 프로 | 1,300B | 100,000원 | 77원 | -23% |
| 비즈니스 | 6,750B | 500,000원 | 74원 | -26% |
| 엔터프라이즈 | 14,300B | 1,000,000원 | 70원 | -30% |

### 소모량 (산출물 단위)
지니젠은 바나나 "생성 1회" 단위지만, 우리는 강의안 산출물 단위로 묶어 과금한다. 내부 원가는 지니젠 단가(영상 초당 약 1.75B, Pro 이미지 5B, 기획 호출 3B)를 기준으로 계산했다.

| 산출물 | 구성 | ro | 원화 환산 |
|---|---|---|---|
| 문서 · HWP | Claude 초안 1회 + HWPX 조립 | **3B** | 300원 |
| 뉴스레터 | Claude 원고 + GPT Image 카톡 이미지 1장 | **8B** | 800원 |
| 카드뉴스 | 장당 GPT Image 1장 (문구 설계 포함) | **5B/장** | 500원/장 |
| 홍보영상 30초 | Claude 설계 3B + Seedance 25초(5+10+10) 44B + 포스터 5B + 합성 | **55B** | 5,500원 |
| 뮤직비디오 1분 | Claude 가사·장면 3B + ElevenLabs 1분 3B + Seedance 60초 105B + 합성 | **110B** | 11,000원 |

예) 베이직 120B로 뉴스레터 15건, 프로 1,300B로 홍보영상 23편 또는 뮤직비디오 11편.

### 규칙
- 작업 시작 시 선차감, 실패 시 전액 자동 환불.
- 구독 없이도 충전 ro로 모든 제작실 사용 가능(구독은 "정기 할인 + 매월 자동 지급"일 뿐 게이트가 아니다).
- 차감 순서: 월 지급분(유효기간 있음) → 충전분.
- 무료 지급분(가입 보너스·관리자 지급)은 환불 대상 아님.

## 3. 구현
- `plan_settings.credit_costs` 기본값을 위 표로 변경, `banana_packages` 테이블 추가(관리자 편집).
- 토스 일반결제(결제창) → `POST /v1/payments/confirm` → `add_credits(reason='purchase:<package>')`.
- `credit_ledger`에 `expires_at` 추가는 하지 않고, 단순화를 위해 월 지급분은 다음 결제일에 `set_credits`로 재설정하되 **충전분은 보존**한다: `profiles.credits`(월 지급, 재설정) + `profiles.banana_purchased`(충전분, 보존) 두 잔고로 관리. 차감은 월 지급분부터.
